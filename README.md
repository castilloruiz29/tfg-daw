
# Plataforma de Peluquerías y Barberías

## Descripción
Desarrollo de una plataforma web especializada en peluquerías y barberías que facilita el contacto entre clientes y establecimientos de su zona.

## Problema que pretende resolver
Muchos pequeños establecimientos todavía gestionan sus citas mediante llamadas telefónicas, WhatsApp o agendas tradicionales. Esto dificulta la organización de las reservas y puede provocar duplicidades y problemas de disponibilidad.

## Funcionalidades principales
- Registro e inicio de sesión de usuarios.
- Gestión de clientes, profesionales y administradores.
- Gestión de establecimientos y servicios.
- Búsqueda de peluquerías y barberías.
- Consulta de horarios, precios y disponibilidad.
- Reservas online y gestión de citas.
- Prevención de solapamientos horarios.
